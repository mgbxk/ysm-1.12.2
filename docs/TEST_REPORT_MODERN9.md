## 环境与验证

Minecraft Java 1.12.2，Forge 14.23.5.2860，Java 8，MixinBooter 10.6，GUI 比例 2，Xvfb / 软件 OpenGL。服务器是仅监听 127.0.0.1 的原版 1.12.2 服务端，没有安装 YSM；日志确认 LOCAL 纯客户端模式。没有新增外部依赖或修改测试模型数据。

`spotlessApply build` 成功。81 项自动检查全部通过，无失败、错误或跳过。4 项新增回归覆盖真实酒狐动画数据的 7 个动作全程、变回人形、同一玩家 ID 的不同预览实例、同一动画时刻姿态还原、只读预览不触发变身时间轴，以及同名动作请求的 NBT 往返与复制。新增回归最初两项在未修改 modern.8 上均失败，保留 baseline-regression-results.xml。

源码修改摘要与复核补丁见 modern9-changes.patch，测试源码与结果 XML 在报告包内。模型文件保持原样；形态和可见性修复在运行时实现。

## 边界

其他未提供的自定义变身模型、完整整合包、服务端同步模式和单独修改的 VanillaFix 启动修补 JAR 未做本次实机验证。通用并行层缩放组合已实现，但不能因此认定所有模型都完全兼容。新版加密 .ysm、粒子与未实现的模组联动仍沿用此前支持范围。

测试环境无法加载 OpenAL，启动与 F3+T 重载时有音频初始化日志，游戏使用 Silent Mode。本次没有验证实际音效播放；已检查的视觉与动作流程没有出现崩溃。

## 安装

退出游戏，移出旧 YSM JAR 备份，将 modern.9 JAR 放入 mods，仅保留一份 YSM；保留现有 MixinBooter 和 config/yes_steve_model/ 模型与外观设置。Alt+Y 打开模型库，Z 打开动作轮盘。无需替换酒狐或蕾米莉亚文件。
