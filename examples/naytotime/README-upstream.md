# 奶油桃 NaytoTime · YSM 模型

> 可以自由使用的ysm模型

这是YSM模型奶油桃（NaytoTime）的仓库

## 快速下载

- **GitHub Releases（推荐）**：前往仓库右侧 **Releases** 页面，下载最新版本的 `NaytoTime.ysm`
- 或直接点击本仓库根目录的 `NaytoTime.ysm`，进入文件页后点 **Download**
- 备用下载：百度网盘 / Google Drive，见文末「模型更新」

## 使用说明

1. 将 `NaytoTime.ysm` 放入 `config\yes_steve_model\custom\` 目录
2. 在游戏内 YSM 模型界面中选择该模型即可使用
3. 可选：下载 `NaytoTime.bbmodel` 可用 Blockbench 打开编辑

# NaytoTime (YSM Model)

> A free-to-use YSM model

## Quick Download

- Visit the **Releases** page for the latest `NaytoTime.ysm`
- Or download `NaytoTime.ysm` directly from the repository root

## How to Use

1. Place the `NaytoTime.ysm` file into the `config\yes_steve_model\custom\` directory.
2. Select the model in the in-game YSM model menu.
3. (Optional) Open `NaytoTime.bbmodel` in Blockbench to edit.
